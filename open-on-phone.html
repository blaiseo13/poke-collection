Make it an app icon

  1. iPhone: open the app code in Safari → tap Share (square with an up arrow, bottom middle) → Add to Home Screen → Add.
  2. Android: open it in Chrome → tap ⋮ (top right) → Add to Home screen (or Install app) → Add.
  3. Tap the new Poké Ball icon: it opens full screen like an app, with no browser bars.
